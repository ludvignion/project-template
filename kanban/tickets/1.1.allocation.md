# 1.1 Exact integer allocation

## Outcome
Split an integer total across integer weights so the parts always sum to the total exactly.

Tracer bullet for brief 1: the first artefact to cross every gate in the harness. It was
chosen to load-bear on all six CI checks — hypothesis, mypy strict, ruff, radon, import-linter,
pytest — so that a green verdict means the harness works, not just that one function does.

## Acceptance criteria

- **AC-1 (behavioral):** Given total `100` and weights `[1, 1, 1]`, When `allocate` is called,
  Then it returns three integers summing to exactly `100`. No part is `33.33`; no remainder is
  dropped.

- **AC-2 (property):** For all non-negative integer totals and all weight vectors of positive
  integers, `sum(allocate(total, weights)) == total`. Write with `hypothesis`
  (`pyproject.toml:8`), not parametrised cases — the point is the unbounded claim.

- **AC-3 (property):** For all valid inputs, every part is within one unit of its exact share:
  `abs(part[i] - total * w[i] / sum(w)) < 1`. Without this, dumping the entire remainder on
  element 0 would satisfy AC-2. The float here is in the *test's* oracle, never in `src/`.

- **AC-4 (critical):** No floating-point arithmetic in the allocation path. Charter item 1
  (`docs/domain-pack/charter.md`) names this the domain non-negotiable — a `float`, `/`, or
  `round()` in `src/app/allocation.py` is a reject, not a finding. Mark for mutation testing.

- **AC-5 (behavioral):** Given weights summing to zero, an empty weight vector, a negative
  total, or any negative weight, When `allocate` is called, Then it raises `ValueError` whose
  message names the offending argument. Chosen over silent clamping so the failure is visible
  at the boundary.

- **AC-6 (critical):** `make ci` exits 0 — ruff check, ruff format, mypy strict, lint-imports,
  pytest, radon. Per AGENTS.md, CI is the only authority on green; paste the output.

## Out of scope

- The remainder rule is unconstrained beyond AC-3. Pick the most boring one that passes
  (largest-remainder is the obvious choice) and note it in the close-out log — it is an open
  ADR candidate in `kanban/1.plan.md`, to be written up after this ships, not decided here.
- Currency, money types, `Decimal`, or any domain model around the quantity. Bare `int`s.
- Import contracts in `.importlinter` — one module forms no layers.
- A second module, a package, or a `MODULE.md`. One file, one public function.
- Renaming the `app` package to a domain name. Real, but not this slice.
