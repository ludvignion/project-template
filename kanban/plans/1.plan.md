# 1 Harness shakedown via an exact-allocation module

## Outcome
I want one small, real, pure-function module built through the full grill → plan → build →
verdict → close-out cycle, so that every gate in the harness is exercised by genuine artifacts
rather than inspected in isolation.

The module is the vehicle, not the point. It was chosen to load-bear on every CI check the
template ships: property tests (`hypothesis`), `mypy --strict`, `radon`, `ruff` complexity
limits, and `import-linter`. A feature that exercised fewer of them would leave parts of the
harness untested.

## Acceptance criteria

- **AC-1 (behavioral):** Given a total of `100` and weights `[1, 1, 1]`, When `allocate` is
  called, Then it returns three integers that sum to exactly `100` — no part is `33.33`, and
  none of the remainder is discarded.

- **AC-2 (property):** For all non-negative integer totals and all weight vectors of positive
  integers, `sum(allocate(total, weights)) == total` holds exactly. Tagged property; written
  with `hypothesis`, which is already a dev dependency (`pyproject.toml:8`).

- **AC-3 (property):** For all valid inputs, each returned part is proportional to its weight
  within one unit — `abs(part[i] - total * w[i] / sum(w)) < 1`. This is what distinguishes a
  correct allocation from one that dumps the whole remainder on the first element.

- **AC-4 (critical):** No floating-point arithmetic appears in the allocation path. Charter
  item 1 (`docs/domain-pack/charter.md`) names this as the domain non-negotiable; the verdict
  checks it. A `float` in the call path is a reject, not a finding.

- **AC-5 (behavioral):** Given a weight vector summing to zero, or a negative total, When
  `allocate` is called, Then it raises `ValueError` with a message naming the offending
  argument. Chosen over silent clamping so the failure is visible at the boundary.

- **AC-6 (critical):** `ruff check`, `ruff format --check`, `mypy src`, `lint-imports`,
  `pytest`, and `radon cc src -n C` all pass. Per AGENTS.md, CI is the only authority on green;
  a claim of green without this output is not accepted at gate 2.

## Out of scope

- Any second feature. One module is enough to load-bear on every gate.
- `make` itself — not installed, and installing it needs an interactive sudo password. See
  Assumption 6; the CI steps are verified to pass when invoked directly.
- Currency, money types, or a domain model around the quantity. `allocate` takes bare integers.
- Fixing the missing `.gitattributes` (Assumption 7). Real, but it is not this slice's work.
- `tests/evals/` — `src/` calls no model, so per AGENTS.md the eval suite stays absent.
- Import contracts in `.importlinter`. One module forms no layers; contracts land when a
  second module gives them something to constrain.

## Modules

- `src/app/allocation.py` — splits an integer total across integer weights without loss.

One module, one function. No package, no `MODULE.md` — AGENTS.md reserves that for deep
modules, and this is a single file.

## Decisions worth an ADR

- **Venv location on WSL.** `UV_PROJECT_ENVIRONMENT` pointing off `/mnt/c` is now load-bearing
  for every `uv` command, and it is recorded nowhere a fresh session would find it. The next
  session, or CI on Linux, will not reproduce this setup from the repo alone.
- **Remainder distribution rule.** AC-3 constrains the parts to within one unit but does not
  say who receives the remainder — largest-remainder, first-N, or round-robin. Any of them
  satisfies the ACs; the choice is worth recording once rather than rediscovering.

## Open findings, not scheduled

- **No `.gitattributes`.** `kanban/briefs/1-test.md` arrived with CRLF line terminators while
  every Python file is LF. Nothing enforces this, so line-ending drift will keep landing in
  diffs from the Windows-side editor. Out of scope here; worth its own brief.
- **`make` is absent.** Every documented command (`make ci`, `make plan N=1`, `make verdict`)
  is unreachable until it is installed. Needs one interactive command from you:
  `sudo apt-get install -y make`.
