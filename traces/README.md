# traces

Machine-written. Do not edit by hand except `grill-misses.jsonl`.

- `grill/<n>.jsonl` — one record per design-tree node.
- `grill-misses.jsonl` — you append at close-out: `{"ticket","finding","category","should_grill_have_caught","missed_question"}`.
- `blind-spots.md` — generated by `make digest`; the grill reads it.
- `verdict/<id>.json|html` — gate 2.
- `plan/<n>.html` — gate 1.
- `golden/<n>/{brief.md,grill.jsonl}` — replay set.
- `sessions.jsonl` — one line per agent turn (Stop hook). Git-ignored.
